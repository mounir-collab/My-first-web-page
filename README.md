# YouTube Homepage Clone

A simple front-end recreation of the YouTube homepage using **HTML and CSS**.

### Features
- Navigation sidebar.
- Header with search bar and user icons.
- Video thumbnail grid.
- Video titles, channel names, views, and upload dates.
- Video duration labels.
- Channel picture tooltips on hover.

### Technologies
- HTML5
- CSS3

### How to Run
1. Clone or download the repository.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
